Make the student laptop open and alert by itself

A website cannot start itself, so each student laptop is prepared once. After that the page starts when Windows starts, stays in the background, and pops up with alarm, voice and a notification when you send an alert.

  1. Host the folder over https, then edit the address at the top of windows-setup/install-student-pc.bat.
  2. On the student laptop, right-click that file and choose Run as administrator, then type the student's name.
  3. It creates a startup shortcut that opens the page full-size with sound allowed, and allows notifications, sound and background running for your site in Chrome and Edge.
  4. Restart the laptop once. The student's name is remembered, so no tap is needed.
  5. Windows: switch off Focus assist / Do not disturb so notifications are never hidden.

The laptop must be switched on and signed in to Windows, and the page window can be minimised but not closed.
